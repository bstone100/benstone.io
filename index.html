    This website!

    I've wanted to learn how to make websites since around 2019, and this is the first website that I really feel like I created myself, as I've coded it myself with just HTML, CSS, and JavaScript. I was inspired to develop this website after I finished Jad Joubran's course on HTML and CSS. For this website I'm just designing it while I code, taking inspiration along the way from other people's websites and from things I've coded before. The style of the website is neumorphic, as I find it aesthetically pleasing. I also used neumorphism in my Sleep Tracker app. I spent a lot of time developing for this website the animation that occurs when you press an image thumbnail and it expands to fill the screen. I wanted the markup to be semantic, so I've used <button> for the thumbnail and <dialog> for the full size image. At first, I used the View Transition API, but I wasn't satisfied with the result, so I switched to CSS anchor positioning, which didn't satisfy me either, so eventually I ditched it and am now using mostly just CSS and a bit of JavaScript to fill in the gaps. Then, I spent a fair bit of time optimizing my page to load as fast as possible. The most impactful thing I did was to make my images AVIF format and then make my <img> elements responsive by providing multiple sizes of each image. Right now I'm working on the content of the website...

  2. Panda Task

    The code on GitHub

    February 2024 - May 2024

    This app started as a school project and eventually got put on the iOS App Store. It was initially a group project for a Human Computer Interaction class I took at UC Davis. The initial premise of the app was how could we make task management software more accessible to people with ADHD. Our idea was to make a task manager with an AI voice assistant that would manage your calendar for you. I coded the app with Qt Widgets in C++ because that was the UI framework and programming language I knew best at the time. Publishing the app to the App Store was a cool experience because I learned how Apple's app review process works. This app may be the only Qt Widgets app published to App Store, at least I couldn't find any others. I eventually took the app down because I didn't want to give everyone free access to OpenAI API requests that I was paying for. If you look through the app's code, you may notice I hard-coded an OpenAI API key. Yup, at the time I didn't understand client-server architectures, but I've learned my lesson, and the key's been revoked. While the app was up, it got over 150 downloads, and there were zero crashes reported across all sessions, which I'm proud of. When I was coding the app, I honestly spent the largest block of development time making the zoom animation that occurs when the user taps a day in the calendar. I enjoy making spatial animations and shared element transitions.

    • Created calendar app featuring an AI assistant and published it to the iOS App Store
